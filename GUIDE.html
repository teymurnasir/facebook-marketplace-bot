1. What it does

  • Searches Canadian Facebook Marketplace for your car filters
  • Sends matching links to the Telegram group Canada car alerts
  • Remembers listing IDs in seen.db so the same post is never sent twice
  • Auto-scan every 30 minutes + instant /scan

2. How it runs online

GitHub Actions

Repo: teymurnasir/facebook-marketplace-bot (private)

Workflow marketplace.yml scrapes Marketplace and sends Telegram messages.

Cloudflare Worker

Instant /scan webhook:

marketplace-telegram-webhook.hello-forward.workers.dev

Account currently used: isa.efendiyev@gmail.com

Day-to-day: leave it alone. Only use a Mac when Facebook login expires (re-save session → update GitHub secret).

3. Telegram commands

CommandResult
/scan (or /search, /run) Starts a Marketplace scan immediately. Group gets progress + results.
/help Short command list.
/id Shows this chat’s Telegram id (needed if group id changes).

Anyone in the authorized group can use commands. History of old alerts is usually visible to new members (unless group history is hidden).

7. Errors → what to do

If Telegram/GitHub shows an error, match it below.

You see Meaning Do this
ERR group chat was upgraded to a supergroup / Telegram 400 Group id changed after upgrade. In the group send /id. Update GitHub secret TELEGRAM_CHAT_ID and Worker secret TELEGRAM_CHAT_IDS to the new id (usually starts with -100).
ERR This chat is not authorized Command came from a chat not in the allow-list. Send /id, add that id to TELEGRAM_CHAT_ID (GitHub) and TELEGRAM_CHAT_IDS (Cloudflare Worker).
ERR Failed to start GitHub scan + 401 / Bad credentials Cloudflare Worker’s GitHub token expired. 
cd telegram-webhook
gh auth token | npx wrangler@4 secret put GITHUB_TOKEN
Then /scan again.
ERR 403 / Resource not accessible Token cannot trigger Actions on the private repo. Create a GitHub PAT with Actions: write (and repo access), put it in Worker secret GITHUB_TOKEN.
ERR 404 workflow dispatch Wrong repo name or workflow missing. Confirm Worker secret GITHUB_REPO=teymurnasir/facebook-marketplace-bot and file .github/workflows/marketplace.yml on main.
WARN Scan finishes with 0 scraped / no cars for a long time Facebook session expired, blocked, or checkpoint. Re-run local python -m src.save_session, update FACEBOOK_STORAGE_STATE_B64, then /scan.
WARN Executable doesn't exist / Playwright browser missing Chromium not installed locally. 
source .venv/bin/activate
playwright install chromium
(Cloud Actions installs browsers itself.)
WARN /scan does nothing for minutes Webhook down, or old polling mode. Check Worker URL is set: Telegram getWebhookInfo should show marketplace-telegram-webhook.hello-forward.workers.dev. Re-deploy Worker if needed. Or run workflow manually in GitHub Actions.
WARN Marketplace scan failed in Telegram Exception during scrape (timeout, crash, FB block). Open the failed run in GitHub Actions → job log. Usually refresh Facebook session or re-run /scan.
INFO Scan finished — no new cars Working. Matches found were already in seen.db. Nothing. Wait for new listings, or reset DB if you want a full resend.
INFO Scan takes 5–15 minutes Normal with current coverage. Wait. Limit is 45 minutes per Actions run.
WARN Same cars sent again after you expected silence seen.db was reset or cloud cache missing. Expected after a DB reset. Otherwise check Actions cache / SEEN_DB_B64 secret still exists.
ERR GitHub Action cancelled / timeout Run exceeded time or concurrency conflict. Re-run /scan. If frequent, reduce hubs/queries in config.yaml or raise timeout-minutes.

Reset database (resend current matches)

Only if you intentionally want every currently found matching ad sent again:

# local empty db
rm -f data/seen.db
python - <<'PY'
import sqlite3
from pathlib import Path
Path('data').mkdir(exist_ok=True)
c=sqlite3.connect('data/seen.db')
c.execute("""CREATE TABLE seen_listings (
  listing_id TEXT PRIMARY KEY,
  search_name TEXT, title TEXT, url TEXT,
  first_seen_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP)""")
c.commit()
PY

base64 < data/seen.db | tr -d '\n' | \
  gh secret set SEEN_DB_B64 -R teymurnasir/facebook-marketplace-bot

# delete old seen-db caches in GitHub Actions UI or:
# gh cache list -R teymurnasir/facebook-marketplace-bot
# gh cache delete <id> -R teymurnasir/facebook-marketplace-bot
